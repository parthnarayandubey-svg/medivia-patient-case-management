Project Description

MEDIVIA (Patient Case Taking Software) is an academic web application designed to simplify the initial case taking and patient record management for small medical clinics or healthcare centers.

The software allows clinic staff to register patients, automatically generate unique Patient IDs, maintain records, and allows medical practitioners to record detailed clinical observations such as symptoms, diagnosis, prescribed medicine, and remarks.

All data is saved locally on the client's browser using HTML5 localStorage, making it completely client-side without any backend database server.

Technologies Used

  • HTML5: Semantic structure, forms, input types, and tables.
  • CSS3: Box model, Flexbox layout, styling, and basic responsive design.
  • JavaScript: DOM manipulation, event handling, loops, arrays, objects, and localStorage API.
