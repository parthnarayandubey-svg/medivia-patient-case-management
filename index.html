Welcome to MEDIVIA

Patient Case Taking Software is a simple web-based system designed for doctors and clinics to manage patient records and clinical case history efficiently.

Developed using pure HTML, CSS, and JavaScript with browser localStorage for data storage.

Key Features

  • Quick patient registration with auto-generated Patient ID.
  • Patient records stored locally in browser using HTML5 localStorage.
  • Search patient records instantly by patient name.
  • Detailed case taking form: Symptoms, Diagnosis, Medicines, and Doctor Remarks.
  • Clean, lightweight, and easy-to-use user interface.
